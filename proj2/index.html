Fun with Filters and Frequencies

Filters, edge detection, and fun techniques using frequency decompositions

Overview

This project covers filters and frequencies and how they can be used for things from edge detection to sharpening / restoring images. I build convolutions from the ground up in part 1, and part 2 covers different frequency decompositions and hacks to make creative images.

Part 1.1: Convolutions from Scratch

A convolution is an operation that can be applied to an image to achieve some intended effect, defined by a kernel. We first flip the kernel (which is needed to guarantee associativity), and then essentially pass the kernel over patches of the image, taking the dot product, and writing that as the output at that point.

Convolution typically requires padding to allow greater use of information around the edges. The two types of padding I implemented were ‘same’, which keeps the output size identical to the input by padding only enough on the sides, and ‘full’, which adds enough pixels that every single pixel, even the edge ones, gets the full amount of processing by the filter.

The four loops method I implemented was 2 outer loops over the image as to where to start my convolution, and two inner loops over the kernel to multiply the kernel with everything inside the relevant patch of the image. The two loops method used NumPy in the inner loop instead.

Padding

def pad_image(image, kernel_shape, padding_type): 
    ks = kernel_shape
    height, width = image.shape
    if padding_type == 'full':
        ret_image = np.zeros((height + 2 * (ks[0] - 1), width + 2 * (ks[1] - 1)))
        ret_image[ks[0] - 1:ks[0] + height - 1, ks[1] - 1:ks[1] + width - 1] = image
    elif padding_type == 'same':
        h, w = (ks[0]) // 2, (ks[1]) // 2
        ret_image = np.zeros((height + (ks[0] - 1), width + (ks[1] - 1)))
        ret_image[h:h + height, w:w + width] = image

    return ret_image

Four loops

def convolve_4loops(image, kernel, padding_type):
    # flip
    kernel = kernel[::-1, ::-1]
    image = pad_image(image, kernel.shape, padding_type)

    h, w = image.shape
    kh, kw = kernel.shape
    out = (h - kh + 1, w - kw + 1)
    result = np.zeros(out)
    for i in range(out[0]):
        for j in range(out[1]):
            # i, j point to a corner; now get the sum for this section
            agg = 0
            for u in range(kh):
                for v in range(kw): 
                    agg += image[i + u, j + v] * kernel[u, v]
            result[i, j] = agg

    return result

Two loops

def convolve_2loops(image, kernel, padding_type): 
    # flip
    kernel = kernel[::-1, ::-1]
    image = pad_image(image, kernel.shape, padding_type)

    h, w = image.shape
    kh, kw = kernel.shape
    out = (h - kh + 1, w - kw + 1)
    result = np.zeros(out)
    for i in range(out[0]):
        for j in range(out[1]):
            # i, j point to a corner; now get the sum for this section
            result[i, j] = np.sum(image[i:i+kh, j:j+kw] *  kernel)

    return result

Part 1.2: Finite Difference Operator

I also tried convolving an image with the finite difference operator, which are two vectors that show the change in the horizontal and vertical directions, allowing them to light up edges in those directions. The gradient magnitude combines them by treating each one as a magnitude and taking the L2 norm of the two different directions. 

Dx, Dy = np.array([[-1, 0, 1]]), np.array([[-1, 0, 1]]).T

def get_gradients(image, x_kernel=Dx, y_kernel=Dy):
    dx = signal.convolve2d(image, x_kernel, mode='same')
    dy = signal.convolve2d(image, y_kernel, mode='same')
    return dx, dy

def grad_magnitude(dx, dy):
    return np.sqrt(dx ** 2 + dy ** 2)

def edges(magnitude, threshold):
    return np.where(magnitude > threshold, 1, 0)

Part 1.3: Derivative of Gaussian Filter

To fix the noisiness in the finite-difference pictures above, we can first blur our image with a Gaussian, which will remove a lot of noise (tends to be high frequency), before taking the gradients. To do this, I ran a 10x10 Gaussian kernel with sigma = 3.0 over the image first before calculating the gradients the same way as before.

Convolution being associative allows us to replace blurring + differentiating with just one operation: convolving with a filter that does both. To get such a filter, we just convolve the Gaussian with the finite difference vectors, something called a derivative of Gaussian filter, and run them over the image individually.

Part 2.1: Image Sharpening

Though in the above part we focused on blurring images with convolutions, it is also possible to use them to “sharpen” images. We can do this by first blurring an image, with a Gaussian filter (which acts as a low-pass filter) to get the low-frequency components. We can subtract the blurred (low frequency components) from the image to only get high frequencies left, and we can add more of those high frequencies to the original image to make it sharper. We control this via a weight, beta, that tells us how much of the high frequencies we want to add back. This can also be done in just convolution, by exploiting the basic “unit” filter and the fact that convolutions are associative

f + β(f − f ∗ g) = f ∗ ((1 + β)e − βg)

def convolve_color(image, kernel):
    if image.ndim == 2:
        return signal.convolve2d(image, kernel, mode='same', boundary='symm')
    return np.dstack([convolve_color(image[..., c], kernel) for c in range(image.shape[2])])

def blur_image(image, kernel_size, sigma):
    gaussian_base = signal.windows.gaussian(M=kernel_size, std=sigma)[:, None]
    kernel = gaussian_base @ gaussian_base.T 
    kernel /= np.sum(kernel)
    return convolve_color(image, kernel)

def high_freq(image, k, sigma):
    blurred_image = blur_image(image, k, sigma)
    return image - blurred_image

def sharpen_image(image, k, sigma, beta):
    h = high_freq(image, k, sigma)
    return np.clip(image + beta * h, 0, 1)
def unsharp_mask_filter(image, k, sigma, beta): 
    unit = np.zeros((k, k))
    unit[k // 2, k // 2] = 1

    gaussian_base = signal.windows.gaussian(M=k, std=sigma)[:, None]
    gaussian = gaussian_base @ gaussian_base.T 
    gaussian /= np.sum(gaussian)

    kernel = (1 + beta) * unit - beta * gaussian
    return np.clip(convolve_color(image, kernel), 0, 1)

Part 2.2: Hybrid Images

We also explore how to make a type of image known as a hybrid image: an image that looks different depending from where you view it. Up close, higher frequencies usually dominate what humans see, whereas further away, humans can only make out low-frequency details. So we add the low-frequency and high-frequency components of two images, using the Gaussian filter and the image minus its Gaussian filter. I align the images using two points of reference that I want to match up, split frequencies based on which picture already seems sharp vs noisy to me, and add the two different frequency components. 

def hybrid_image(im1, im2, sigma1, sigma2):
    low_pass = blur_image(im1, 6 * sigma1 + 1, sigma1)
    high_pass = high_freq(im2, 6 * sigma2 + 1, sigma2)

    return np.clip(low_pass + high_pass, 0, 1)

Part 2.3: Gaussian and Laplacian Stacks

Next, we’re going to play around with image stacks: these are the equivalent of image pyramids minus the downsampling at every stage; we replace it with a size-preserving convolution instead. We implement both Gaussian stacks, where we blur at every single level, by an amount that doubles every iteration, and Laplacian stacks, which are the difference of adjacent Gaussian levels in a stack. 

def gaussian_stack(image, depth, sigma): 
    stack = []
    stack.append(image)
    for i in range(1, depth):
        curr_sigma = sigma * 2 ** (i - 1)
        stack.append(blur_image(image, 6 * curr_sigma + 1, curr_sigma))
    return np.stack(stack)

def laplacian_stack(image, depth, sigma): 
    gaussian = gaussian_stack(image, depth, sigma)
    stack = []
    for i in range(depth - 1):
        stack.append(gaussian[i] - gaussian[i+1])
    stack.append(gaussian[depth - 1])
    return np.stack(stack)

Part 2.4: Multiresolution Blending

These results are based on a paper on multiresolution blending that uses these stacks to put together images with hard to blend or see seams. Both images first get split into Laplacian stacks, the mask into a Gaussian one, and each level is blended for the purpose of finer details getting blended over a narrow seam. All the levels are then added back up. All of the blends here use 5 levels and sigma=2 each. 

def blend_stacks(im1, im2, mask, depth, sigma):
    l1 = laplacian_stack(im1, depth, sigma)
    l2 = laplacian_stack(im2, depth, sigma)
    gm = gaussian_stack(mask, depth, sigma)
    if im1.ndim == 3:
        gm = gm[..., None]
    return gm * l1, (1 - gm) * l2

def blend(im1, im2, mask, depth, sigma):
    left, right = blend_stacks(im1, im2, mask, depth, sigma)
    return np.clip(np.sum(left + right, axis=0), 0, 1)

def vertical_mask(shape):
    mask = np.zeros(shape[:2])
    mask[:, :shape[1] // 2] = 1
    return mask

def load_mask(fname):
    return (load_image(fname) > 0.5).astype(float)

What I learned

The most important thing I learned in this project is how far you can go in image processing using purely all of these concepts and algorithms based on frequencies. I never thought that classical computer vision could even include the effects that we created, let alone that it was caused by something as intuitive as processing images based on their frequency domain. I also didn’t know that all these transformations like Gaussian blurring and unsharpening, hybrid images, etc could be expressed via very simple frequency-domain concepts.
